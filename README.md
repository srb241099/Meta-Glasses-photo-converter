# Meta Glasses Photo Converter PWA

Mobile-first PWA version.

## Features
- Mobile app-style UI
- Installable PWA
- Offline app shell
- 3024 × 4032 JPEG output
- 95% JPEG quality
- Center-crop without stretching
- EXIF compatibility labels
- Share / Save / Base64
- Client-side processing only

## GitHub Pages
1. Upload all files/folders to repository root.
2. Settings → Pages
3. Source: Deploy from a branch
4. Branch: main
5. Folder: /(root)
6. Save

## iPhone
Open the GitHub Pages URL in Safari → Share → Add to Home Screen.

## Android
Open in Chrome → Install app / Add to Home screen.
